# Maturaarbeit

Dieses Repository beinhaltet alle relevanten Dateien für meinen Schachbot, den ich als Maturaarbeit gemacht habe.
Die neuste Version ist chess_new_1_opt.cpp. Die Testprojekte sowie die Rohdaten zu meinen Tests an der Engine
finden Sie in den entsprechenden Ordnern. 

Falls sie die Engine testen wollen, können sie jedoch nicht einfach die Datei laufen lassen. 
Um die Engine zu benutzen können sie einerseits die Engine in eine Umgebung einfügen, die
UCI unterstützt. Andererseits sie können Sie auch den Code kopieren, den Funktionscall
uciloop(board) zusammen mit dem darunterliegenden '/*' entfernen und den Code einfach so laufen lassen.
